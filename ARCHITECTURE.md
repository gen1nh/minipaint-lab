# Architecture
Local-first modular React application. Proposed: Vite, TypeScript strict, Tailwind, accessible UI primitives, IndexedDB via Dexie when persistence is implemented. App composes features; features depend on domain, shared UI and explicit persistence interfaces, not other features. Domain has no UI or infrastructure dependencies. Infrastructure implements domain ports. Introduce folders only when needed. Use versioned schemas for imports and migrations. GitHub Pages deployment uses repository base path and hash routing unless another routing strategy is documented. No backend or authentication in MVP. Test domain with Vitest and journeys with Playwright; add lint and CI when scaffolding application. No tool dependencies installed yet.
