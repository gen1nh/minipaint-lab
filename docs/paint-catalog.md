# Universal paint catalog
Initial snapshot: 3933 rows across eight brand files under public/catalog. Source: Arcturus5404/miniature-paints, MIT; see licenses/miniature-paints.txt. Each JSON contains source URL and blob SHA. Rows are [name, code, range, hex]. Exact duplicate tuples removed within each brand; distinct ranges and conflicting codes retained. Source colors are not physically calibrated and may include discontinued paints or non-mixable specialty products. No inventory or accounts. Search directly in mixer, custom colors only when needed. Citadel and Scale75 not imported in this batch because the source parser did not return matching rows; inspect their source format before adding. Do not import restricted third-party data. Local build and test execution blocked by network DNS in the working environment; CI verification pending. Catalog picker loads static JSON, limits displayed matches to 30, and provides custom fallback on failure.
