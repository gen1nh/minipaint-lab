# Release workflow
Develop on develop or feature branches. GitHub Actions validates pushes to develop and main and PRs targeting either. Cancel superseded runs per ref. Cache npm downloads; use npm ci when a real lockfile exists. Generate and commit package-lock.json using npm, never handwrite it. Merge a validated release to main via squash PR. Vercel git.deploymentEnabled allows main and disables other branches (https://vercel.com/docs/project-configuration/git-configuration). No GitHub Pages deployment. Configure required CI / validate check and PR requirement for main in repository settings; do not require a Vercel preview check on develop. Verify settings and actual deployment behavior before declaring enforcement complete. Existing rate limits are not reset by this configuration.
